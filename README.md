📊 Excel Sales Analysis Dashboard — Global Superstore 2016

📌 Project Overview

This project is part of my Data Analyst Course – Week 1: Excel & Data Fundamentals.

The project focuses on data cleaning, data analysis, descriptive statistics, Pivot-style summaries, conditional formatting, and dashboard creation using Microsoft Excel.

The analysis uses the Global Superstore 2016 dataset to understand sales performance across regions, categories, and years.

---

🎯 Project Objectives

- Clean and prepare the sales dataset
- Remove duplicate records
- Handle missing values
- Analyze region-wise sales
- Calculate Mean, Median, and Mode
- Identify the Top 10 Sales values
- Analyze category-wise revenue
- Analyze yearly sales trends
- Create an interactive-style Excel sales dashboard

---

🧹 Data Cleaning

The following cleaning steps were performed:

1. Removed duplicate records.
2. Handled missing numeric values using the respective column median.
3. Handled missing text values by replacing them with "Unknown".
4. Created a "Year" column from the Order Date.

Dataset Size

- Original Records: 51,290
- Cleaned Records: 51,290

📈 Analysis Performed

1. Region-wise Sales

Created a summary of total sales by region to compare regional performance.

2. Sales by Category

Analyzed revenue generated by different product categories.

3. Yearly Sales Trends

Analyzed sales performance across different years.

4. Descriptive Statistics

Calculated:

- Mean

5. Top 10 Sales

Applied Excel conditional formatting to highlight the Top 10 Sales values.
